# 🏠 房貸試算工具

一個功能完整的房貸試算工具，支援寬限期、多階段利率、額外提前還款、多方案比較與雲端存檔。

## ✨ 功能特色

- **單一方案試算**：支援寬限期、單一利率/兩階段/三階段浮動利率
- **每月應繳金額**：結果區直接顯示「寬限期後每月應繳」與「寬限期月付」
- **還款方式**：本息均攤、本金均攤
- **額外提前還款**：可新增多筆提前還款，自動計算省下的利息
- **視覺化圖表**：每月還款組成、剩餘本金曲線
- **攤還明細表**：完整每期本金/利息/剩餘本金
- **多方案比較**：同時比較多個方案的利率、月付金、利息、剩餘本金
- **雲端存檔**：透過 Google Sheets 儲存與管理你的方案
- **載入並編輯**：已存方案可載入回表單繼續修改，並直接更新原方案（或另存新方案）
- **利率資訊**：我的方案與比較表都會列出各階段利率與期間

## 🚀 快速開始

### 安裝套件
pip install -r requirements.txt

### 執行
streamlit run loan_app.py

### 設定 Google Sheets（存檔功能）
在 .streamlit/secrets.toml 中設定連接資訊

## 💡 使用小提醒

- **載入並編輯**：在「我的方案」按「✏️ 載入並編輯」後會自動跳回試算頁並帶入設定、自動重算；修改完按「💾 更新方案」覆蓋原方案，或按「📄 另存為新方案」保留原本的存檔。
- **編輯中**：試算頁上方會顯示編輯提示，按「✖️ 取消編輯（回到預設值）」即可離開編輯模式。
- **重新計算**：改過設定後若未按「🚀 開始計算」，儲存前會提醒先重新計算，避免存到上一次的試算數字。
- **舊存檔相容**：早期存檔沒有「每月應繳」時，會自動用方案設定重算補上；`updated_at` 欄位也會自動建立。
