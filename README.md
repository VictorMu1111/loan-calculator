# 🏠 房貸試算工具

一個功能完整的房貸試算工具，支援寬限期、多階段利率、額外提前還款、多方案比較與雲端存檔。

## ✨ 功能特色

- **單一方案試算**：支援寬限期、單一利率/兩階段/三階段浮動利率
- **還款方式**：本息均攤、本金均攤
- **額外提前還款**：可新增多筆提前還款，自動計算省下的利息
- **視覺化圖表**：每月還款組成、剩餘本金曲線
- **攤還明細表**：完整每期本金/利息/剩餘本金
- **多方案比較**：同時比較多個方案的利息、月付金、剩餘本金
- **雲端存檔**：透過 Google Sheets 儲存與管理你的方案

## 🚀 快速開始

### 安裝套件
pip install -r requirements.txt

### 執行
streamlit run loan_app.py

### 設定 Google Sheets（存檔功能）
在 .streamlit/secrets.toml 中設定連接資訊

## 📁 專案結構
loan_app.py + modules/ 資料夾結構
